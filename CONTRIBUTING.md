# Contributing to DMMapp

Thanks for your interest in the DMMapp Directory. There are two main ways to contribute:

## Add a library

Help us map the world's digitized manuscript collections.

[Learn how to add or edit libraries →](./docs/update-data.md)

## Report a data issue

On a library page, select **Report a data issue** to open a form that already
identifies the record. [Learn what to include](./docs/update-data.md#report-a-data-issue).

## Update the code

Improve the dashboard, documentation, or project infrastructure.

[See the developer guide →](./docs/contributing.md)

---

Have questions? [Open an issue](https://github.com/SexyCodicology/Digitized-Medieval-Manuscripts-app/issues) or reach out to @Dioscorides.

Please also read our [Code of Conduct](./CODE_OF_CONDUCT.md) before participating.

We appreciate your contributions! 🙌
