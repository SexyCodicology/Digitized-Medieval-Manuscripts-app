# About DMMapp

## Our mission

DMMapp (Digitized Medieval Manuscripts Application) helps people discover
digitized medieval manuscript collections from libraries around the world. It
brings links to those collections together in one searchable directory for
study, teaching, and personal interest.

The directory does not host digitized manuscripts. It helps readers find the
institutions and platforms that do.

## Project stewardship

SexyCodicology publishes DMMapp as an open-source project. The repository
identifies [@Dioscorides](https://github.com/Dioscorides) as the code owner for
the directory data and schema, and the contribution guidance names that account
as the reviewer for data submissions.

The repository does not name an institutional sponsor or publish a broader
maintainer roster. If you need help with the project, use the public channels
listed below.

## Where the links come from

The directory records links to digitized medieval manuscript collections. People
can propose new entries and corrections through the project's public
[data-update guide](update-data.md). Changes are reviewed before they become
part of the published directory.

Each linked collection remains responsible for its own website, access
conditions, metadata, images, and rights statements. Check the source
institution's terms before reusing material from a collection.

## Reuse and licensing

DMMapp is dedicated to the public domain under the
[CC0 1.0 Universal license](https://github.com/SexyCodicology/Digitized-Medieval-Manuscripts-app/blob/master/LICENSE).
You can copy, adapt, and redistribute the project's directory data and site
content without requesting permission.

This license does not apply to material held by the libraries and platforms
linked from DMMapp. Each directory entry includes the rights information
available for that collection, but you should confirm the source institution's
current terms before reuse.

## How the site is built

DMMapp is a static site built with MkDocs and Material for MkDocs. Its
searchable directory uses a JSON data file, which the build process validates
before publishing the site.

## How we write

DMMapp writes for students, manuscript enthusiasts, and the general public. We
use a welcoming, explanatory style that introduces specialized terms in plain
language and favors clear headings, short paragraphs, and direct links to
digitized resources.

Our public-facing copy follows *The Chicago Manual of Style* (CMOS) and uses
standard American English. We use serial commas, headline-style capitalization
for headings, and spell out whole numbers below one hundred in running text. We
preserve verified institution names, manuscript shelfmarks, links, captions,
and attribution statements.
