# Expansion!

Hi everyone! Couple of news concerning both the blog and the DMMapp.
**Sexy Codicology Blog news**
Have you checked our "Medieval Scripts" section recently? No? Well, we are currently working on expanding our website and we are now writing texts concerning medieval writing styles.
The idea here is to provide visitors with a good starting point for studying medieval scripts further. **We will reference all the scholarly sources used while wring the text via footnotes**, so that students and researchers can find the same reading material we used to carry out their own research, or simply order a nice book from their library and read further.
There is a lot to write, so the project will take quite some time. Many scripts will start with a brief description only, but will be expanded over time.
In the main "Medieval Scripts" page, you will also find links to other great websites that have interesting content concerning the writing styles.
**DMMapp updates**
The **"Report Broken Link" feature** we recently developed in our app is proving to be a success, and extremely useful to us! Before, we would have to run a manual check on all the systems and wait for the response of all the websites we had in the DMMapp, then interpret the results, then edit the JSON.
No more! Now, whenever we get a notification of a broken link, we can quickly act and try to fix the issue.
Also, there is now a [DMMapp plugin](https://chrome.google.com/webstore/detail/dmmapp-plugin/lfddboglgfimpmokggiapioogkhgical)! Yep, on Chrome, Opera, and Firefox, you can quickly find the same repositories we have added to the DMMapp, without going to the DMMapp first.
Awesome!
