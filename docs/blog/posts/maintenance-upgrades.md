# Maintenance &amp; upgrades!

We have just released a **crucial update** for the DMMapp.
While nothing visible changed on the website itself, on the back-end of the app it is a whole other story!
Without going into too many boring technical details:

<!-- more -->

- **We can now update the database and add additional metadata with just a few clicks.**

"Why is this so great?" You may ask. Well, the answer is that when we set up the DMMapp back in the day, we had in mind to create a simple app that "should just work" and link to repositories with medieval manuscripts.
But, we can do so much more to help and link more useful tools!
For example:
Besides the individual repositories, there are also aggregators, portals, and other websites, that contain a wealth of interesting informations about manuscripts. We want to link to these too!
Or whenever we publish an overview of a repository containing medieval manuscripts on the Sexy Codicology blog, we can now add the link to the post in the DMMapp's database and have a link appear in the "Data" section of the DMMapp.
These kind of posts are great, as they explain how to access the manuscripts, what to expect from the repository, and which amazing books are there to be seen.
The aim of this is to help the DMMapp users discover great repositories and reduce the guessing game when browsing through the DMMapp. 
**We are thrilled with the results! There's so much more we can do now.**
Thank you for your support! It really wouldn't be possible without!
And stay tuned for even more updates!
