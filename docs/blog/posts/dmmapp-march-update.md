# DMMapp March Update

Thanks to the many reports we have received over the past couple of months we are happy to announce that the DMMapp is approching the end of its "Beta". Planned for the end of the month!

<!-- more -->

## **What has the Sexy Codicology Team been doing?**

- Updated the database thanks to the feedback of our users that kindly reported data errors and new entries.
- A couple of weeks ago we **moved our Sexy Codicology website and the DMMapp to new, faster, servers.** The migration went quite well, except a couple of hiccups that took us offline for a few hours.
- Started working on the DMMapp API

### **Wait! Whad did you say? DMMapp API?**

Yes. We want to allow other users (researchers, developers, enthusiasts, anyone who might want to use the DMMapp data) to be able to create their own application, or integrate our data into something that already exists.
This can quickly turn into an intricate mess, so we will be starting very simple by allowing all our users to read and browse our data from an endpoint.
There is a lot to be done (testing, writing documentation, bug fixing, etc.) but we think this can really be useful and is the next step for the DMMapp project! So we'll put 110% effort into this.
Stay tuned! And if you have any ideas / requests for the DMMapp API, let us know!
