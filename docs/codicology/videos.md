# Sexy Codicology Videos

At Sexy Codicology we always try to find new ways to spread interest in medieval manuscripts. One way we do this is by making short movies, using excellent high-resolution, copyright-free images from institutions like the [Getty Museum](../libraries/the-j-paul-getty-museum-560.md).

You can find us on [YouTube](https://www.youtube.com/user/SexyCodicology?cbrd=1&ucbcb=1).
